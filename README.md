# Forma 3D Toolkit: Lighting starter site (v2)

This branch holds the Lighting starter site for the [Forma 3D Toolkit](https://wordpress.org/plugins/forma-3d-toolkit/) plugin. The plugin downloads it as a zip package (tag `starter-lighting-v2`) when you choose "Lighting" in Appearance > Forma Setup and click Import.

- `demo.json`: categories, products, homepage blocks, tagline and store settings.
- `models/`: true-to-scale 3D models (glTF binary, meshopt-compressed, WebP textures).
- `images/`: three product photos per model (WebP, rendered from the models).
