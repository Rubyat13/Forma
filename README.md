# Forma 3D Toolkit: Fashion starter site (v1)

This branch holds the Fashion starter site for the [Forma 3D Toolkit](https://wordpress.org/plugins/forma-3d-toolkit/) plugin. The plugin downloads it as a zip package (tag `starter-fashion-v1`) when you choose "Fashion" in Appearance > Forma Setup and click Import.

- `demo.json`: categories, products, the homepage (with the "Try the Look" block), tagline and store settings.
- `images/`: six full-body look photos (`look-*.webp`) and one detail crop per product (WebP with transparent backgrounds).
