A WooCommerce theme for stores that show products as interactive 3D models.

== Description ==

Forma 3D is a WooCommerce theme for stores that sell physical products and want shoppers to see every angle.

* A scroll-animated homepage: your featured products turn in real 3D as visitors scroll, categories glide sideways and a close-up section points out details.
* A shop with a 3D quick view: rotate, zoom and add to cart without leaving the page.
* Product pages built around a large 3D stage. Install the free "3D Viewer" plugin by bPlugins for rotate, zoom, a dimensions ruler and "View in your room" (AR) on supported phones.
* Ready for the block editor: theme.json colours, fonts and button styles, editor styles and block patterns.
* A cart drawer that updates without reloading the page.

The theme works without any plugin. With WooCommerce it becomes a store; with the 3D Viewer plugin products get their 3D models.

== Installation ==

1. In your admin, go to Appearance > Themes > Add New Theme and search for "Forma 3D", or upload the theme zip.
2. Activate the theme.
3. Install WooCommerce to sell products, and the free "3D Viewer" plugin to add 3D models to them.
4. Go to Settings > Reading and choose a static page as your homepage to show the 3D homepage.
5. Appearance > Customize > Forma 3D options holds the footer call to action and the product page notes.

== Frequently Asked Questions ==

= How do I add a 3D model to a product? =

Install the 3D Viewer plugin, edit a product, add your .glb file in "3D Product Settings" and choose "Replace Product Image with 3D".

= Which products appear on the homepage? =

Featured products with a 3D model. Mark a product as featured with the star in Products.

= Does the theme work with the block editor? =

Yes. Colours, fonts and buttons come from theme.json, and the "Forma 3D" pattern category has ready-made sections.
